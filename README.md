# QR Code Generator (Python)

This is a simple Python project that generates a QR code for any user-provided link.

## 🔹 Features
- Takes any URL or text as input
- Generates a QR code image instantly
- Simple and beginner-friendly Python project
- Useful for sharing links quickly

## 🔹 Technologies Used
- Python
- qrcode library
- Pillow (PIL)

## 🔹 How It Works
1. User enters a link or text
2. Program generates a QR code
3. QR code is saved as an image file

pip install qrcode[pil]
